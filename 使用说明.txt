Paste-boss 使用说明
================================

【安装（绿色版，只有一个 exe）】
  1. 把 paste-boss.exe 放到任意文件夹（建议单独建一个，例如 D:\Tools\Paste-boss），双击即可运行。
     不写注册表、不装服务、没有安装向导，删掉 exe 就等于卸载。
  2. 双击后窗口不会自己弹出来 —— 程序在后台待命，按 Alt+V 才呼出面板，
     同时右下角通知区会出现托盘图标（可能被折叠进「^」里）。
  3. 想开机自动启动：面板 ⚙ 设置 → 打开「开机自启」开关（只写当前用户的 Run 键，随时可关）。
  要求系统里已有 WebView2：Windows 11 自带；Windows 10 1803 以后多数已自带。
  没有的话装一个免费的 “Microsoft Edge WebView2 Runtime” 即可（微软官网可下载）。
  首次运行若出现「Windows 已保护你的电脑」蓝框：点「更多信息 → 仍要运行」即可。
  这是因为 exe 没有购买数字签名证书，并不是病毒；也可以在文件属性里勾「解除锁定」。

【打开面板】
  程序启动后窗口是隐藏的，按 Alt+V 呼出，再按 Alt+V 收起。
  （Alt+V 是默认值，觉得不顺手可以在「设置 → 呼出快捷键」里换成别的组合。）
  面板会像 Win+V 一样，直接弹在**你正在打字的地方**旁边（贴着文字光标下方），
  鼠标不用再跑到屏幕右上角；当前窗口没有文字光标时（桌面、看图、视频等）弹在鼠标附近。
  快要超出屏幕时会自动往回收，靠近屏幕底部时改成弹在光标上方。
  任务栏右下角通知区会出现本程序的托盘图标（就是 exe 的那个图标，可能被折叠进「^」里）：
  左键单击托盘图标 = 显示/收起面板，和快捷键一样；
  右键单击 = 菜单（显示面板 / 暂停记录 / 打开数据目录 / 清空历史 / 设置 / 退出）。
  没粘贴过内容时，点一下别的窗口它会自动收起（像系统剪贴板工具那样“用完就走”）；
  粘贴完之后面板会留在屏幕上，什么时候关由你自己决定（按快捷键或 Esc 收起）。
  不想让它自己消失：点标题栏右边的 📌（图钉）常驻，之后点别的窗口、按 Win 键都不会收起；
  再点一次 📌 恢复「点别处自动收起」。这个选择会记住，重启后照旧。

【拖动 / 缩放窗口】
  面板可以随便摆：按住窗口最上面的标题栏，或者面板顶部那一条空白处，直接拖到想放的位置；
  拖窗口的边框 / 四角可以缩放大小（最小 420×320，放大后卡片会跟着变多列）。
  点标题栏、拖窗口、拖边框缩放都不会再让面板突然消失（以前一碰标题栏就没了）。

【基本用法】
  · 复制过的文字和截图会自动出现在面板里，最新的在最前面，默认最多保留 20 条
    （设置里可以改成 20 / 50 / 100 / 200 条）。
  · 卡片右下角的 ✕ 可以删掉这一条（图片的原图文件也会一起删掉）。
  · 单击任意卡片 = 直接把原始内容粘进你刚才用的那个窗口（不用再按 Ctrl+V）。
    粘贴后面板不会自动关闭，可以接着贴下一条；不需要了就按快捷键收起。
  · 不想用鼠标：↑ ↓ 在卡片之间移动（列表会自动跟着滚），Home / End 跳到第一张 / 最后一张，
    空格把当前这张加入或移出多选，Enter 粘贴（没多选时贴当前这张）。
  · 面板失焦/关闭后记录还在，关掉程序再打开也还在（历史存在本机）。

【多选粘贴（文字、图片可以混着选）】
  · Ctrl + 单击：一条一条挑（卡片左上角数字 = 拼起来的先后顺序，从 1 开始）。
  · Shift + 单击：从上次点的那条连选到这条。
  · 按 Enter（或点底部「粘贴 N 条」）：
      - 选中的文字：按“先复制的在前”的顺序，用换行拼成一段粘贴；
      - 选中的图片：作为“图片文件”一次性放进剪贴板，聊天窗口里按一次 Ctrl+V
        就能把多张图一起发出去（微信 / QQ / 钉钉 / 飞书等聊天框都支持）；
      - 文字和图片混着选时：自动分两步贴出去，
        第一步只把文字放进剪贴板贴一次（文字进聊天输入框 / 编辑器），
        第二步再只把图片放进剪贴板贴一次（图片作为附件跟上），
        所以文字和图片都不会丢（以前一次 Ctrl+V 目标窗口只会取其中一种）。
  · 只选一条时和单击卡片完全一样（单张图片会直接以图片形式粘贴）。
  · 粘贴后选择状态会保留，可以再按 Enter 贴一次，或按 Esc 取消选择。

【搜索】
  · 顶部搜索框直接输入，或按 Ctrl+F 跳到搜索框。
  · 匹配的是完整文字（卡片上被省略的后半段也能搜到），不区分大小写。
  · 搜索状态下 Ctrl+A 只选中搜到的卡片；清空搜索框恢复全部历史。

【设置（面板右上角 ⚙ 图标）】
  · 呼出快捷键：点「修改」后直接按下想要的组合键，立刻生效并记住。
      规则：必须包含 Ctrl / Alt / Win 之一，例如 Ctrl+Alt+V、Ctrl+Shift+Space、Win+Space。
      如果提示「已经被其它程序占用」，换一个组合即可（此时旧快捷键仍然可用，不会两个都没了）。
      录制中按 Esc 取消。
  · 开机自启：打开开关后，登录 Windows 会自动在后台启动本程序
    （不弹窗口、只占托盘，按呼出快捷键显示面板）；关掉开关即取消。
    这项设置写在当前用户的注册表 Run 键里，不需要管理员权限，也不用拖快捷方式。
  · 暂停记录：打开开关后，复制的内容不再入库；托盘菜单里也能切换
    （菜单项前面打勾 = 正在暂停）。暂停只在本次运行有效，重启后自动恢复记录。
  · 常驻显示：打开后切到别的窗口、按 Win 键都不会自动收起，只能按快捷键 / Esc / 点关闭收起来；
    和标题栏上的 📌 是同一个开关，设置会记进 config.json。
  · 历史条数：最多保留多少条，选完立刻生效，超出上限的旧记录会被丢弃。
  · 数据目录：这一行显示数据存放位置，点「打开」用资源管理器打开它，
    点「日志」直接定位到运行日志（反馈问题时把它一起发出来最快）。
  · 清空历史：一键删掉全部记录和截图原图（会先确认一次，删掉就找不回来了）。
  · 设置面板打开时按 Esc 或点面板外的空白处即可关闭。

【Esc 逐层退出】
  设置面板打开时第一次按 Esc 关掉设置面板；
  平时第一次按 Esc 清空搜索 → 第二次取消多选 → 第三次收起面板。

【退出程序】
  · 右键单击右下角的托盘图标 → 点「退出」，这是彻底退出的唯一入口。
  · 点窗口右上角关闭按钮（或按 Alt+F4）只是把面板收进托盘，程序仍在后台记录剪贴板。
  · 也可以任务管理器里结束 paste-boss.exe。

【其它小贴士】
  · 开机自启：打开面板右上角 ⚙ 设置 → 打开「开机自启」开关即可（随时可以关掉）。
  · 想让托盘图标一直露在外面、不藏在「^」里：点任务栏的「^」展开，
    把本程序的图标按住拖到任务栏上即可（Win11 也可以在 设置 → 个性化 → 任务栏 →
    「其它系统托盘图标」里把它打开）。
  · 历史存放位置：%APPDATA%\com.tauri-app.paste-boss
    （history.json 是记录清单，blobs 文件夹是截图的原始图片，
      config.json 存设置，logs\paste-boss.log 是运行日志）
  · 想清空全部历史：面板 ⚙ 设置 →「清空历史」；
    或者退出程序后删除上面那个 com.tauri-app.paste-boss 文件夹。
  · 想查日志：打开 logs\paste-boss.log，程序出问题时把它发出来就能定位
    （也可以直接点 设置 → 数据目录 那一行的「日志」按钮）。
  · 本程序只允许开一份：再双击一次 exe 不会开第二个进程，而是把已经开着的面板呼出来。

【遇到问题】
  · 按快捷键没反应：可能这个组合被别的程序占用了，或者是你之前把它改成别的键了 ——
    打开 设置 看「呼出快捷键」那一行写的是什么，点「修改」重新按一个即可。
    也可能本程序已经开了一份（这时再双击一次 exe 会把面板呼出来，不会开出第二个进程）。
  · 单击卡片只复制没粘贴：Windows 会拦截往“以管理员身份运行”的窗口发送按键，
    这时内容已经在剪贴板里了，手动 Ctrl+V 即可。
